# AlyaOS - Interactive Desktop Portfolio

A responsive portfolio prototype inspired by a laptop desktop. Built with HTML, CSS and vanilla JavaScript, so it can run locally and be published through GitHub Pages without Node.js, React or MySQL.

## Project structure

- `index.html` - desktop structure and app windows
- `css/style.css` - wallpaper, desktop, windows and responsive styling
- `js/main.js` - window interactions, project notes, presentation slides, search and clock
- `assets/` - add your resume PDF and original project screenshots here

## Run in VS Code

1. Extract the ZIP file.
2. Open the extracted `alya-portfolio-fixed` folder in VS Code.
3. Install the `Live Server` extension by Ritwick Dey if you have not already.
4. Right-click `index.html` and choose **Open with Live Server**.
5. The site should open in your browser. Click desktop icons to open the app windows.

You can also open `index.html` directly in a modern browser, but Live Server is recommended while editing.

## Publish to GitHub Pages

1. Create a new GitHub repository, for example `alya-portfolio`.
2. Upload the contents of this folder to the repository root. The `index.html` file must be at the root.
3. Commit the files to the `main` branch.
4. In GitHub, open **Settings > Pages**.
5. Choose **Deploy from a branch**, select `main` and folder `/(root)`, then save.
6. Wait for the deployment and open the URL shown in GitHub Pages settings.

Keep the existing Teuland repository unchanged until this new site is tested and ready.

## Before publishing

- Add screenshots and real Figma/live website links for each project.
- Add the resume PDF at `assets/Alya-Resume.pdf` and link it from the Resume window if you want a download button.
- Replace the LinkedIn placeholder with your exact public profile URL.
- Clarify your own contribution to team projects.
- Add only outcomes and metrics that can be verified and are allowed to be shared.
- Keep private client data out of screenshots.

Project summaries are based on the supplied CV. No performance metrics or unverified outcomes have been invented.
